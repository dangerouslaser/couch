# Offline IR catalog provenance

`catalog.json` is generated by `tools/ir/update_catalog.py` from
[Lucaslhm/Flipper-IRDB](https://github.com/Lucaslhm/Flipper-IRDB), pinned at
`d126fb1b6f1e114c52b4a8c19839ea65e3a9c24d`. Each entry carries its source URL,
introduction commit, Git blob ID, SHA-256 and license. `LICENSE-CC0.txt` is the
upstream license at that revision.

The upstream README explicitly excludes commits before
`2319685f2cbf0cd3f809609622cade14d24fb819` from its CC0 contribution policy.
Consequently this is a deliberately limited subset: new paths introduced after
that boundary, excluding detected renames, byte-identical older blobs,
converted database markers, and unsupported file headers. It covers TV,
receiver, soundbar, streaming, projector, DVD and VCR categories. It is not an
assertion that all upstream files are CC0. The policy and source history are the
redistribution evidence; upstream contributors remain responsible for their
submissions. Do not extend the subset to older or converted files without a
separate rights review.

To reproduce with a full-history local checkout:

```sh
python3 tools/ir/update_catalog.py build/irdb-source
```

No hardware has been verified merely by including a code. An exact model match
is preferable; brand matching alone does not establish compatibility. The LG
DVX7900 entry is a VCR/DVD remote, not evidence for LG webOS TV power commands.
