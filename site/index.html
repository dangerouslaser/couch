SANYTRON ASTRION HA100

Linux for your
universal remote.

Control lights, media players, TVs,
and receivers from one remote.

Couch replaces Android on the HA100 with a custom Linux kernel, Rust integrations, and a Slint touchscreen interface.

INTEGRATIONS

  • Kodi
  • Philips Hue
  • Home Assistant
  • LG webOS
  • Denon

FEATURES

Remote features.

01

Physical controls

Use the D-pad, volume, playback, and other hardware keys to control devices. Assign activity buttons to device commands, including supported long presses.

02

Rooms and activities

Group devices into rooms, recall Hue scenes, and configure activities. Kodi and webOS have dedicated control screens.

03

Web configuration

Add connections, arrange rooms and areas, and edit button mappings in your browser. Change the accent color and remote settings there too.

PROJECT STATUS

Early development.

The OS and integrations are running on development hardware. The USB installer is still experimental, and there is no ready-to-flash public release. The application and kernel repositories contain the source, build instructions, and current development notes.
