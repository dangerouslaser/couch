# Couch landing page

Static GitHub Pages site; publish this directory as the artifact root. No build or JavaScript dependencies. All URLs are relative so project Pages paths work.

Preview from the repository root with `python3 -m http.server 8098 --directory site`.

The palette and typography follow `docs/mockups/webos-activity/`: warm paper `#eeeae5`, ink `#25232c`, muted text `#68626f`, and purple `#c4a2ff`. The Couch wordmark uses Inter at weight 800 and letter spacing −2px. The HTML/CSS device is explicitly labeled as an illustrative preview, not a photograph or current UI screenshot.

Inter is bundled under the SIL Open Font License; see `assets/INTER-LICENSE.txt`. No external artwork, analytics, fonts, or scripts are loaded.
